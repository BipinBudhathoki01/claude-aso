# ASO specialist result contract

Every specialist task should return concise, evidence-linked sections. Use local paths/fields for local data and source URLs for live research:

1. **Findings** — observed problems or strengths, each linked to a supplied file/field/row/asset or bundled source.
2. **Unknowns** — missing evidence, unmeasured values, and checks that could not run.
3. **Hypotheses** — plausible explanations or opportunities that are not established by the evidence.
4. **Actions** — prioritized, concrete next steps with effort and a validation metric when known.
5. **Checks run** — helper commands, files, and agent checklist actually used; state when work was sequential or delegated.

Include `used / max_limit` counts with every proposed Play title, short description, Apple name/subtitle, and Apple keyword string. Do not invent rankings, traffic, competitor evidence, causal lift, policy approval, or model/agent execution.
