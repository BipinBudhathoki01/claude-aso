# Google Play Console Extension

Connect live Play Store listings, Android Vitals metrics, and Review Replies using a Google Cloud Service Account with `https://www.googleapis.com/auth/androidpublisher`.

## Supported Capabilities
- Pull live `edits.listings` across locales
- Fetch `reviews.list` and post `reviews.reply`
- Query Play Developer Reporting API for user-perceived Crash & ANR rates
