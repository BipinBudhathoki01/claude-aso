# Apple App Store Connect Extension

Connect live iOS/macOS App Store Connect metadata, Customer Reviews, and Custom Product Pages using an App Store Connect API Key (`.p8` ES256 JWT).

## Supported Capabilities
- Read/update `appStoreVersionLocalizations` (Subtitle, Promotional Text, Keywords, Description)
- Fetch `customerReviews` and submit `customerReviewResponses`
- Inspect `appCustomProductPages` performance
