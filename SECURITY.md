# Security

Do not disclose vulnerabilities, API keys, account credentials, or private store data in public issues. Use this repository's GitHub Security tab to report a vulnerability privately when enabled, or contact the maintainer through their GitHub profile.

The pack executes Python helpers only when your AI runtime permits it. Public iTunes helpers send the supplied app ID or search term to Apple. Other helpers run locally. Your AI runtime may send content to its configured model provider; redact personal or confidential data first.

No authenticated Play Console or App Store Connect integration is included. Extension documents are guidance, not authorization to change accounts.
