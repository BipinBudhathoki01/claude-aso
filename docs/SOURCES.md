# Store guidance and evidence

Last checked: 2026-11-15. Recheck official guidance before submission; the store console is the final validator. Local character checks count Unicode code points and may differ from platform validation for composed text or emoji.

- [Google Play listing setup](https://support.google.com/googleplay/android-developer/answer/9859152): title, short description, and full description constraints.
- [Google Play listing performance reports](https://support.google.com/googleplay/android-developer/answer/9859173): current listing visitor/click metrics and Console export workflow.
- [Google Play Developer Reporting API](https://developers.google.com/play/developer/reporting): Android vitals API; not store listing CTR or visitor reporting.
- [Android vitals](https://support.google.com/googleplay/android-developer/answer/9844486): overall user-perceived crash and ANR thresholds are 1.09% and 0.47%. Meeting or exceeding a threshold is flagged locally. Per-device metrics and other quality requirements need separate Console review.
- [Apple product page](https://developer.apple.com/app-store/product-page/): name, subtitle, keywords, promotional text, and description guidance.
- [Apple app information](https://developer.apple.com/help/app-store-connect/reference/app-information/app-information): app name requirements.
- [Apple review guidelines](https://developer.apple.com/app-store/review/guidelines/): truthful metadata and review policy.

Fixed keyword-density targets, guaranteed ranking lifts, guaranteed AI citations, and fixed cross-locale indexing matrices are not validated platform rules. Removing redundant keywords is optimization advice, not a universal rejection condition.
